# AESTHETIC AND VIBE
This document defines the "soul" of the portfolio. It dictates the copy, the colors, and the feeling the user should get when they visit.

## Tone of Voice
- **Copywriting:** Confident, concise, and professional but approachable. No cliché phrases like "I am a passionate developer." Instead, use action-oriented phrases like "Building scalable digital experiences."
- **Humor:** Dry and subtle. Confident enough to let the work speak for itself.

## Design System & UI Vibe
- **Theme:** Strict Dark Mode default. Deep, rich blacks (`#0A0A0A`) with subtle glowing accents (e.g., an electric blue or neon purple). 
- **Typography:** Modern, hyper-clean sans-serif (e.g., Inter, Geist, or SF Pro). Huge, bold hero text, highly readable paragraph text.
- **Animations:** "Show, don't tell." Use micro-interactions. Buttons should scale slightly on hover. Page transitions should be fluid but fast (no slow, laggy fades). 
- **Layout:** Grid-based, brutalist but elegant. Lots of negative (white/black) space. High contrast. 

## The Core Message
The visitor (recruiters, senior engineers) should land on the page and immediately think: "This person understands clean architecture and modern web design."
